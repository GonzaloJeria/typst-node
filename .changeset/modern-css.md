Modern CSS: cascade layers, media queries evaluated against the page size, `@supports`, `@property`, CSS nesting, Selectors Level 4 (`:is`, `:where`, `:not`, `:has`, sibling combinators, `An+B of S`, escaped class names), `oklch()`/`lab()`/`color-mix()` and other CSS Color 4/5 functions, `min()`/`max()`/`clamp()`, viewport units, logical properties, the `font` shorthand and content-box widths. Compiled Tailwind v4 and Bootstrap 5 stylesheets now apply. Headings take their size and weight from CSS (browser defaults: `h1` is 2em) instead of Typst's heading styles.
